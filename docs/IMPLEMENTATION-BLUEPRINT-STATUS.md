# Implementation blueprint integration · 3 October 2026

The supplied `BannerFlow-Implementation-Blueprint.md` is a proposed product specification. Its embedded example prompts are not separate user commands. This change implements the browser-first path in the existing JavaScript application; optional deployments, account setup, model downloads, new licenses and production approvals are not implied.

## Available behavior

- **Create** opens a saved, connected image/copy generation graph. Typed Image, Copy, Analyze, optional Qwen, Compose and Format nodes control the actual generation run. It uses each selected market's immutable uploaded source, exact supplied copy, loaded typography, manual focal region and connected sizes. 300×250, 728×90 and 1080×1920 are starter targets; custom sizes and existing market sizes are configurable. New Format nodes auto-connect; their own controls run one format, queue it behind an active run, expose fit/decision evidence, download a native PNG, and accept/open the result in Studio. Graph positions, links and settings survive reload and verified backup.
- Strict fitting is opt-in, versioned as `fitPolicy: strict-v1`. Legacy layouts retain their original shrink-to-fit behavior. Strict text uses a finite descending font-size search, preserves hard breaks and nonbreaking compounds, and returns overflow instead of silently shrinking below the minimum. Preview and encoding use this same fitter.
- Seven authored **draft** variants are available. Selecting them authorizes candidate evaluation, not brand approval. The bounded solver measures text, checks required roles/exact strings, safe bounds, separated layer boxes, potentially obscuring decorative layers, solid-background contrast, manual subject-box retention and locks. It ranks only candidates that pass these checks and records rejected candidates. Rotated/animated automatic layouts are explicitly blocked for review; they are not falsely certified.
- Results retain their input snapshot, source bindings, engine version, hash, selected candidate, measurements and decision evidence. Accepting valid drafts updates only local banner overrides, appends history and supports undo. It rejects changed campaign/blueprint inputs and changed asset corrections. Previous masters are unchanged; missing sizes receive draft entries. Accepted copy becomes an explicit local text override.
- Generated exports use frozen campaign bindings and native shared-renderer pixels. Every requested target appears in the ZIP manifest, including blocked/failed/cancelled targets. Successful PNGs are decoded to verify dimensions and carry SHA-256, byte counts and draft status. Campaign exports also account for failures and configured size-limit blockers. No automatic production approval is issued.
- The asset library supports importing/reusing sources, filename/tag/OCR-text search, type filters, manual focal/metadata corrections, hidden-asset tombstones, quota inspection and persistent-storage requests. Hiding retains original bytes for existing campaigns/history/backups.
- Optional analysis actions persist independent records for pixels, subject boxes and OCR. Pixel analysis uses the existing local OpenCV runtime. Tesseract OCR uses installed language packs (English in this environment). An unavailable component does not remove a usable asset. Manual corrections remain separate from inference results.
- Optional SigLIP NaFlex image/text encoding has a pinned-profile contract, normalized vectors, query/image cache, reference-image similarity, exact ranking in a browser worker, stable ordering, prefilters and reciprocal rank fusion. Similarity is never presented as correctness probability. Filename/tag search remains available when semantic encoding is absent.
- Qwen planning defaults on in Create and uses portable CUDA/CPU selection. It is a local adapter for the requested 3B family. It receives bounded previews and allowed IDs/variants, returns a strict CreativePlan, and cannot execute tools/code or change supplied copy. Unknown fields, unauthorized IDs and changed bindings are rejected. One schema repair is allowed, then deterministic fallback. Plans are cached with profile/input provenance. Advisory critique/improvement rounds are not enabled.
- A transactional IndexedDB generation ledger provides idempotent enqueueing, finite attempts, lease expiry, monotonic fencing tokens, cancellation and atomic result/outbox commits. Interrupted generation can be rerun after its lease expires; former lease owners cannot commit. Results are not applied to campaigns automatically.
- Workspace backups include originals, derivatives, saved generation results, correction history and analysis/vector records. Checksums, path and expansion limits, schema validation and referenced asset hashes are checked before restoring project state. Verified backups can repair corrupted local blob contents under the same source identity. Heavy intelligence is kept outside the project snapshot during normal use. Models are excluded explicitly.
- The previously unfinished local image tools are connected: source-preserving cutouts, upscales, background extensions, aligned subject overlays, optional contrast treatments, palette suggestions, file-size targets, automatic GIF parts and editable reference-region proposals. Missing reference roles are labeled **assumed**. Existing-size proposals remain unsaved until explicitly saved.
- Optional local GIF/WebP/video import produces a bounded set of PNG frame derivatives with source frame indexes/timestamps. Animated-image disposal is composited by Pillow; video probing and extraction use installed FFmpeg. Original media remains hashed and unchanged. Frames can be reused, analyzed and searched like other images. This is sampled-frame retrieval, not a claim of continuous video understanding.

## Migration and rollback

All existing schemaVersion 1 blueprints remain valid. New layer properties, derivative/media metadata, generation history and optional campaign treatments are additive and opt-in; opening an old project does not enable strict fitting or inference. The new intelligence database is `bannerflow-intelligence-v1`; original project/blob keys are unchanged. Historical master revisions are preserved. Use **Undo generation** before later manual edits, or restore a verified workspace backup. Older app versions do not understand strict/cutout layers and must not be used to resave new work; retain an older-version backup when rolling back application code.

## Acceptance boundaries and remaining work

This is a tested local implementation, not completion of every production gate in the proposal.

- Approved logos, original campaign photography, production fonts, market policies, reference-matched variants and reviewer signoff are still required. UI thresholds are draft configuration, not universal legal/channel requirements.
- Qwen2.5-VL-3B is **installed**, with both shards and the real processor checked. Trained inference is not run on this 16 GB/no-CUDA build machine. Portable CUDA/CPU selection is implemented and tested with hardware fixtures; actual CUDA inference and model quality await a qualifying destination machine. `google/siglip2-base-patch16-naflex` remains uninstalled. Their real-checkpoint inference smoke tests remain opt-in. Adapter contracts/fallbacks do not establish trained-model quality. An unrelated installed fixed-resolution SigLIP model is intentionally not substituted.
- No human-labeled multilingual retrieval corpus or layout-acceptance baseline was supplied. Ranking/profile isolation tests and evaluation metric functions are available; there are no fabricated Recall@K, quality or latency claims.
- Full cmap/glyph-coverage auditing, dictionary-based hyphenation, rich text runs, RTL/CJK production typography, exact mask-based retention, arbitrary rotated polygon conflicts and rendered-background contrast certification are not implemented by the strict solver. Current checks use measured Canvas text and conservative separated geometry.
- Generation can expand selected sizes across selected markets and export a combined accounted matrix. Each market uses its own supplied copy and assets. Translation generation, production approval and automatic copy rewriting are not enabled; current-market editing remains isolated.
- The Create graph has typed ports, add/remove/reconnect, zoom and preview nodes. It is a bounded banner-generation workflow, not an arbitrary ComfyUI engine: user-defined executable/model nodes, video graphs, Lluna graph import and inline Studio layer editing are not implemented. Accepted outputs open the existing Studio editor. The optional Qwen node ranks layouts; it does not draw final pixels or replace strict validation.
- Generation ledger leases protect jobs; existing legacy project autosaves are not a general multi-tab compare-and-swap project authority. Scheduling requires the app open, explicit rerun resumes expired jobs, and model work may finish after cancellation but cannot commit a cancelled generation. There is no unattended worker daemon, background recipe scheduler or optional SQLite authority.
- Generation automatically gathers bounded OpenCV/OCR/SAM evidence and reuses manual focus; other asset-library analysis jobs remain explicit actions; a complete dependency scheduler, analysis revision assembly UI, rejected-tag editor, garbage collection and a fully transactional project-plus-intelligence restore activation are future work. Restore verifies first; failed blob writes can leave only unreferenced content-addressed blobs, not a replaced active project.
- Video frame sampling is implemented; shot detection, tracked subject identities, crop-path smoothing, audio/transcript retrieval and video timeline encoding are not. Existing GIF generation/export remains supported.
- Reference extraction estimates regions, not original fonts, hidden pixels or exact editable source layers. Automatic halos are suggestions, not accessibility certification. Image-model adapter fixture tests are separate from trained-model quality evaluation.
- Output verification checks decoded dimensions and same-runtime pixel parity in tests. It does not yet perform every proposed final-frame/encoded-palette/glyph/visibility certification for every production channel.

## Verification record

Current checks and visual evidence are recorded in `STATUS.md`. New deterministic tests cover strict overflow, copy preservation, stable fingerprints/candidate ordering, hard locks, profile isolation, planner containment, market isolation, immutable masters and undo. Browser tests cover all three starter dimensions, native PNG parity, impossible copy, fallback, reload, backup/correction portability and expired/cancelled lease fencing. Service tests cover local-origin/input limits, unavailable models, real installed OCR, irregular GIF timing and source preservation. Fixture-based SAM/image-tool tests are not trained model evaluation.


## Automatic generation and hardware follow-up

Create now searches all compatible variants by default, with manual selection behind a checkbox. Its own preserve-boxes option defaults off, while per-layer locks and selected manual focus remain authoritative. The bounded solver scores Qwen's valid variant ranking as a soft preference, preserves all permitted fallback candidates and tries whole-image containment on the banner background when cropping fails. `imageFit` is an optional shared-renderer property; absent means legacy cover. Containment can be disabled by policy and cannot bypass a crop lock. Subject coverage checks clip to the image frame before counting text overlap.

The batch freezes analysis/focus and uses the same evidence for solving and export. Unknown subjects fall back to retaining the whole source; automatic analysis never overwrites manual campaign focus or source assets. Existing generated batches retain their history and must be regenerated for solver version 2. Qwen's selected device/dtype and setup reasons are visible, and `qwen:download`, `qwen:check`, `qwen:smoke` support installation/verification on each machine. See [portable activation and application memory budgets](../services/README.md#portable-qwen-activation).
