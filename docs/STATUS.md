## Evidence and limitations

Supplied references include NetBet FI and Joker5, both with Finnish copy. UK templates are proposals, not reproductions. No original hero, standalone brand logo or production font is present. The demo photo crop and fallback text wordmark remain draft assets. The FI legal line is transcribed reference text; UK legal starts empty. Stored publication metadata does not imply legal/regulatory approval.

These templates reproduce broad layout rules, not exact reference pixels. Red text glow is now available as an editable effect. The rising-arrow offer asset and exact brand typography still need production assets. Reference image files are evidence; current rendered snapshots cannot be called approved golden masters.

The editor is desktop-oriented (minimum 920 px wide). The campaign review interface adapts to mobile. GIF export is synchronous per sampled frame with event-loop yields, at 10 fps for animated effects; it is bounded to 120 million sampled pixels. Static/cut GIF timing matches the supplied files. No worker/server encoder or animated WebP yet. Finite GIF repeat applies to export; editing playback always cycles.

Images support opaque-background fades, cover crop, direct panning and opacity. Text supports glow and geometry-based space suggestions. Local OWL-ViT detection and manual region selection now guide smart crops. Detection can miss small/stylized subjects; a fixed cover frame cannot always preserve the whole subject or avoid every overlay. Review flagged crops. Arbitrary masks, blend modes, image blur/shadow controls, subject segmentation and automatic reference extraction are not implemented. OpenCV analyzes imagery; it does not infer legal or brand compliance.

The native SAM 3 checkout at `/home/dexter/Desktop/projects/sam3` still requires CUDA and a native checkpoint. The default service now uses Hugging Face Transformers 5.17.0 in `.venv-sam3`, which supports CPU without that checkout. Local authentication and the full trained Hugging Face weights are now installed. The real application test found four person/face matches in the football reference photo, taking 34.4 seconds on the warmed CPU service. Focus persisted and PNG export matched the arranged preview exactly. This validates one reference image; production-image accuracy still requires review. Browser AI remains a faster option and the automatic fallback. Separate HTTP fixtures and a tiny random-model CPU test cover integration and failure paths. See [service setup and limitations](../services/README.md).

Existing version history is retained in project data; the reference library does not edit or roll back versions. There is no multi-user account, cloud sync, deployment, campaign-history browser or permission system. One active campaign per market is supported. Browser storage can be evicted; use workspace backups. Asset-level delete/reuse management, per-platform file-size caps and automatic batch optimization remain future work.
